# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-09-17

### Added
- Added command-line file-size parsing and conversion to KB, MB, and GB.
- Added validation and tests for supported and unsupported size units.

### Removed
- Removed the unused `file.txt` scratch file.

## [0.2.0] - 2026-09-17

### Added
- Added triangle shapes with base and height area calculations.
- Added largest-shape selection and output based on area.
